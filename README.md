# WindowMerger - 窗口合并工具

## 功能特性

- **窗口合并**：将多个应用程序窗口合并到一个窗口中
- **标签切换**：通过顶部标签页快速切换不同窗口
- **任务栏隐藏**：合并后的窗口不在任务栏显示图标
- **系统托盘**：软件仅在系统托盘运行
- **快捷键**：可自定义快捷键打开/隐藏窗口
- **自动合并**：通过正则表达式自动合并匹配的窗口
- **Home页**：默认首页，可选择已打开的窗口进行合并

## 系统要求

- Windows 10 x64

## 使用方法

### 基本操作

1. **运行程序**：双击 `WindowMerger.exe` 启动程序
2. **主界面**：启动后显示 Home 页，列出所有可用的窗口
3. **合并窗口**：在 Home 页点击要合并的窗口编号（如 `[1]`）
4. **切换窗口**：点击顶部标签页或使用快捷键
5. **关闭标签**：点击标签右侧的 `×` 按钮

### 快捷键

| 快捷键 | 功能 |
|-------|------|
| Ctrl+Shift+O | 打开/隐藏主窗口 |
| Ctrl+Tab | 切换到下一个标签 |
| Ctrl+Shift+Tab | 切换到上一个标签 |
| Ctrl+W | 关闭当前标签 |
| Ctrl+1-9 | 快速切换到对应标签 |

### 托盘菜单

右键点击系统托盘图标：
- **Show Window** - 显示主窗口
- **Hide Window** - 隐藏主窗口
- **Settings** - 打开设置
- **Exit** - 退出程序

1. 部分应用程序可能不支持窗口合并
2. 首次运行建议先在 Home 页熟悉操作
3. 如遇快捷键冲突，请在设置中修改
4. 软件启动后会自动隐藏任务栏图标
