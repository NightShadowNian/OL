# WindowMerger - 窗口合并工具

## 功能特性

- **窗口合并**：将多个应用程序窗口合并到一个窗口中
- **标签切换**：通过顶部标签页快速切换不同窗口
- **任务栏隐藏**：合并后的窗口不在任务栏显示图标
- **系统托盘**：软件仅在系统托盘运行
- **快捷键**：可自定义快捷键打开/隐藏窗口
- **自动合并**：通过正则表达式自动合并匹配的窗口

## 系统要求

- Windows 10 x64

## 使用方法

1. **运行程序**：双击 `WindowMerger.exe` 启动程序
2. **合并窗口**：手动拖拽窗口或通过自动合并规则
3. **切换窗口**：点击标签页或使用快捷键
4. **打开/隐藏**：按 `Ctrl+Shift+O` 切换窗口显示
5. **托盘菜单**：右键点击托盘图标可打开设置或退出

## 快捷键

| 快捷键 | 功能 |
|-------|------|
| Ctrl+Shift+O | 打开/隐藏主窗口 |
| Ctrl+Tab | 切换到下一个标签 |
| Ctrl+Shift+Tab | 切换到上一个标签 |
| Ctrl+W | 关闭当前标签 |
| Ctrl+1-9 | 快速切换到对应标签 |

## 配置文件

配置文件位置：`%APPDATA%\WindowMerger\config.json`
