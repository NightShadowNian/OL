# 窗口合并工具设计文档

## 1. 概述

### 1.1 项目背景
本软件是一款 Windows 平台的窗口管理工具，旨在将多个应用程序窗口合并到一个带有标签页的容器窗口中，通过顶部标签进行切换，实现任务栏图标最小化，提升用户桌面整洁度和工作效率。

### 1.2 核心目标
- 将多个软件窗口合并到一个窗口，通过标签页切换
- 合并后的软件在后台正常运行，任务栏不显示图标
- 记录合并记录，支持自动合并
- 软件仅在系统托盘显示，无任务栏图标
- 支持快捷键快速打开/隐藏合并窗口
- 提供完整的设置功能

### 1.3 目标平台
- Windows 10 x64（主要目标）
- 预留跨平台扩展空间

## 3. 技术方案

### 3.1 架构设计

采用**代理窗口模式**，核心思想：
- 创建主容器窗口，包含标签栏和内容区域
- 目标窗口保持独立运行，通过消息转发实现显示
- 使用 Win32 API 控制窗口行为

### 3.2 关键技术实现

#### 3.2.1 窗口合并机制

**代理窗口模式实现步骤：**

1. **窗口检测**：通过 `EnumWindows` API 遍历所有顶层窗口
2. **窗口识别**：过滤出主程序窗口（排除对话框、工具窗口等）
3. **代理创建**：为每个目标窗口创建对应的代理窗口
4. **消息转发**：捕获目标窗口的 WM_PAINT 等消息，转发到代理窗口显示
5. **任务栏隐藏**：设置目标窗口的 `WS_EX_TOOLWINDOW` 扩展样式，或使用 `ITaskbarList3::DeleteTab`

**窗口过滤规则：**
- 排除子窗口（`GetParent(hwnd) != NULL`）
- 排除工具窗口（`GetWindowLongPtr(hwnd, GWL_EXSTYLE) & WS_EX_TOOLWINDOW`）
- 排除最小化窗口（可选配置）
- 排除特定进程（如本软件自身）

#### 3.2.3 快捷键管理

**快捷键冲突检测流程：**

```
启动时
    │
    ▼
遍历所有注册快捷键
    │
    ▼
调用 RegisterHotKey 尝试注册
    │
    ├─ 成功 → 快捷键可用
    │
    └─ 失败 → 标记冲突，记录冲突信息
        │
        ▼
显示冲突警告，禁用冲突快捷键
    │
    ▼
用户修改后重新检测
```

**快捷键配置结构：**

| 快捷键ID | 默认值 | 功能 |
|---------|-------|------|
| SHORTCUT_TOGGLE | Ctrl+Shift+O | 打开/隐藏主窗口 |
| SHORTCUT_NEXT_TAB | Ctrl+Tab | 切换到下一个标签 |
| SHORTCUT_PREV_TAB | Ctrl+Shift+Tab | 切换到上一个标签 |
| SHORTCUT_CLOSE_TAB | Ctrl+W | 关闭当前标签 |
| SHORTCUT_TAB_1-9 | Ctrl+1~9 | 快速切换到对应标签 |

#### 3.2.4 自动合并机制

**自动合并规则结构：**

```cpp
struct AutoMergeRule {
    std::wstring name;           // 规则名称
    std::wstring pattern;        // 正则表达式模式
    bool enabled;                // 是否启用
    std::wstring workspace;      // 所属工作区间
};
```

**自动合并流程：**

```
系统窗口创建事件
    │
    ▼
获取窗口标题
    │
    ▼
遍历自动合并规则
    │
    ▼
正则表达式匹配
    │
    ├─ 匹配成功 → 自动合并到容器
    │
    └─ 匹配失败 → 忽略
```

## 5. 安全性考虑

### 5.1 权限要求
- 普通用户权限即可运行
- 无需管理员权限（除非需要监控系统级进程）

### 5.2 进程隔离
- 不修改目标进程内存
- 仅通过 Windows API 进行窗口消息交互
- 目标进程崩溃不影响本软件

### 5.3 配置安全
- 配置文件仅存储本地信息
- 不包含敏感数据
- JSON 格式便于备份和迁移

## 6. 性能优化

### 6.1 资源占用优化
- 使用原生 Win32 API，避免框架开销
- 按需创建代理窗口，不预分配资源
- 窗口隐藏时暂停消息转发

### 6.2 消息处理优化
- 使用消息过滤器减少不必要的消息处理
- 批量处理窗口枚举和状态更新
- 使用定时器定期检查窗口状态，避免轮询过频
